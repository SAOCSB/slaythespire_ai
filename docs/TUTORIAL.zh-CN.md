# SpirePilot 中文使用教程

这篇教程带你从零开始：装好 Mod、接上 AI、让它帮你打一局，再到联机时让 AI 和队友沟通。
所有按钮和开关的名字都和游戏里面板上显示的一致。功能的完整说明见 [README](../README.md)，实机测试清单见 [TESTING.md](TESTING.md)。

> ⚠️ SpirePilot 是实验性 Mod：作者没有在开发环境里实际运行过游戏，某些界面上 AI 可能会卡住。
> AI 卡住时会自动暂停，不会乱点；遇到问题请看本文最后一节“反馈问题”。

## 1. 准备工作

你需要：

- **《杀戮尖塔 2》**（Steam 版）。
- **一个 AI 接口**，任选一种：
  - 在线服务：DeepSeek、通义千问、Kimi、智谱 GLM、硅基流动、Anthropic Claude、OpenAI、Gemini、OpenRouter……
    去对应网站注册并创建一个 **API Key**（一串以 `sk-` 等开头的密钥）。在线服务按用量计费。
  - 本地模型：在自己电脑上运行 Ollama 或 LM Studio，不需要密钥、不花钱，但需要较好的显卡，效果取决于模型大小。
- 大致费用：AI 每做一次决策大约消耗 2000–6000 个输入 token；战斗中 AI 会一次规划整个回合以减少调用次数。
  面板会显示累计的调用次数和 token 数，方便你估算（见[第 13 节](#13-省钱小技巧)）。

## 2. 下载对应版本

《杀戮尖塔 2》目前有两个分支，接口互不兼容，要下载和你的游戏对应的包：

| 你的游戏 | 游戏版本 | 下载这个包 |
| --- | --- | --- |
| Steam 默认（正式分支） | 0.107.x | `SpirePilot-<版本>-game0.107.zip` |
| Steam 测试分支（public-beta） | 0.111.x | `SpirePilot-<版本>-game0.111.zip` |

不确定自己的版本？游戏主菜单的角落会显示版本号。装错了也没关系，Mod 会在面板里用红色提示告诉你该换哪个包（见[第 12 节](#12-版本提示红色和黄色)）。

## 3. 安装

1. 解压下载的 zip，里面有一个 `SpirePilot` 文件夹。
2. 把这个文件夹放进游戏目录下的 `mods` 文件夹（没有就新建一个）：
   - Windows：`C:\Program Files (x86)\Steam\steamapps\common\Slay the Spire 2\mods\SpirePilot\`
   - Linux / Steam Deck：`~/.local/share/Steam/steamapps/common/Slay the Spire 2/mods/SpirePilot/`
   - macOS：`~/Library/Application Support/Steam/steamapps/common/Slay the Spire 2/mods/SpirePilot/`

   找不到游戏目录：在 Steam 库里右键游戏 →“管理”→“浏览本地文件”。
3. 检查：`mods\SpirePilot\` 里应该有 `SpirePilot.dll` 和 `mod_manifest.json`。
   **不要在 `mods` 文件夹里放其它 `.json` 文件**（游戏会把所有 json 当作 Mod 清单读取）。
4. 启动游戏，按提示同意加载 Mod。加载 Mod 后游戏会使用单独的 Mod 存档，你原来的存档不受影响。

## 4. 打开控制面板

进入游戏后，SpirePilot 面板默认已经显示在屏幕左上方。没看到面板时，按 **F8** 或点屏幕**右侧边缘**的 **“AI”** 小按钮打开它。

- 拖动面板标题栏可以移动面板，拖动右下角的抓手可以调整大小；再按一次 F8（或点“AI”按钮、标题栏右边的 **×**）把它收起来。
- 不想每次启动都显示面板，可以在“日志”页的“其他设置”里关掉“启动游戏时显示面板”；快捷键、界面语言、界面缩放也在那里改。

面板有六个页签：

| 页签 | 用来做什么 |
| --- | --- |
| **控制** | 选择 AI 的模式（关闭 / 全自动 / 仅战斗 / 仅非战斗 / 顾问），暂停、单步，查看 AI 的建议和当前局面，给 AI 下临时指令 |
| **路线** | 路线偏好、房间权重、推荐路线、固定路线 |
| **角色** | 允许 AI 使用哪些角色、怎么挑、进阶等级、长期的打法要求 |
| **队友** | 联机时的队伍聊天、快捷请求、表情、队友状态，以及 AI 和队友交流的开关 |
| **API** | 接入 AI 服务：服务商、地址、密钥、模型、代理等 |
| **日志** | AI 做了什么、出错原因、诊断报告、本地 HTTP 接口，以及界面相关的其他设置 |

设置会自动保存（面板底部会显示“设置已保存”）。只有 **API** 页需要手动点“保存”。

## 5. 接入 AI（API 页）

### 5.1 添加一个配置（以 DeepSeek 为例）

1. 打开 **API** 页。
2. 在“从模板添加”的下拉框里选 **DeepSeek 深度求索**，点 **添加**。
   新配置会自动成为“使用中”的配置，并在下方打开编辑。
3. 在 **API Key** 一栏粘贴你的密钥（点“显示”可以看到内容，确认没粘错）。
4. 点 **测试连接**。成功时会显示类似：`连接成功 · 1.23 秒 · 模型 deepseek-chat · 回复: …`。
5. 点 **保存**。（有没保存的修改时，按钮旁会提示“有未保存的修改”；也可以点“还原”放弃修改。）

其他服务商一样操作，模板已经填好了接口地址和一个默认模型，模型名可以改成你想用的：

| 模板 | 接口地址 | 模板里的默认模型 |
| --- | --- | --- |
| Anthropic Claude | `https://api.anthropic.com` | `claude-opus-5-5` |
| OpenAI | `https://api.openai.com/v1` | `gpt-5` |
| DeepSeek 深度求索 | `https://api.deepseek.com/v1` | `deepseek-chat` |
| 通义千问 Qwen (DashScope) | `https://dashscope.aliyuncs.com/compatible-mode/v1` | `qwen-plus` |
| Moonshot Kimi | `https://api.moonshot.cn/v1` | `kimi-latest` |
| 智谱 GLM | `https://open.bigmodel.cn/api/paas/v4` | `glm-4.6` |
| 硅基流动 SiliconFlow | `https://api.siliconflow.cn/v1` | `deepseek-ai/DeepSeek-V3` |
| OpenRouter | `https://openrouter.ai/api/v1` | `openrouter/auto` |
| Google Gemini (OpenAI-compatible) | `https://generativelanguage.googleapis.com/v1beta/openai` | `gemini-2.5-flash` |
| Ollama (local) | `http://127.0.0.1:11434/v1` | `qwen2.5:14b` |
| LM Studio (local) | `http://127.0.0.1:1234/v1` | （填你在 LM Studio 里加载的模型名） |
| Custom / 自定义 | 预填 `http://127.0.0.1:8000/v1`，改成你的接口地址 | 自己填 |

其他兼容 OpenAI 接口的服务都可以用“Custom / 自定义”：协议选“OpenAI 兼容”，接口地址一般以 `/v1` 结尾。

### 5.2 保护你的密钥

密钥只保存在本机的设置文件里，不会写进日志。不想明文保存的话，可以在 API Key 一栏写 `env:变量名`
（例如 `env:DEEPSEEK_API_KEY`），Mod 会从系统环境变量里读取。
设置环境变量后要**完全退出 Steam 再重新打开**：游戏由 Steam 启动，沿用的是 Steam 启动时的环境变量，只重启游戏读不到
（还不行就注销后重新登录）。没读到时 API 页会提示“缺少 API Key”。

### 5.3 代理

在国内访问海外服务（Claude、OpenAI、Gemini、OpenRouter）时，在“代理地址”里填你的代理，例如 `http://127.0.0.1:7890`。
留空表示使用系统代理。

### 5.4 本地模型（Ollama / LM Studio）

- **Ollama**：安装后在命令行运行 `ollama pull qwen2.5:14b`（或你想用的模型），然后用“Ollama (local)”模板添加配置。
  不需要密钥。Ollama 默认的上下文长度较小，请在 Ollama 里把上下文长度调大，否则 AI 看不全游戏状态。
- **LM Studio**：在 LM Studio 里加载模型并启动本地服务器，用“LM Studio (local)”模板添加配置，在“模型”里填加载的模型名。
- 局域网里另一台电脑上的服务器（如 `http://192.168.1.20:11434/v1`）也不需要密钥。
- 本地模型在 CPU 上可能要几分钟才回答一次，这两个模板的超时已经设为 300 秒。

### 5.5 其他选项

| 选项 | 说明 |
| --- | --- |
| 思考强度 / 战斗回合思考强度 | 推理模型想多久。地图、奖励、商店等用“思考强度”，战斗回合用“战斗回合思考强度”（低一点更快更省）。Claude 模板默认 medium / low；Claude 只提供 low、medium、high、xhigh、max。“思考强度”留“（默认）”就是不发送，由服务器用它自己的默认值；“战斗回合思考强度”留“（默认）”表示战斗回合也用“思考强度”的值 |
| 最大输出 tokens / 超时（秒） | Claude、OpenAI、Gemini、智谱、OpenRouter 模板已为推理模型留足了输出（16000 以上）和时间（300 秒），本地模板超时也是 300 秒。DeepSeek、通义千问、Kimi、硅基流动和“自定义”模板是 8192 tokens / 120 秒：换成推理模型（例如 `deepseek-reasoner`）时，请把最大输出调到 16000 以上、超时调到 300 秒 |
| 温度 | 留空 = 不发送（推荐）。对 Claude 不会发送 |
| JSON 输出模式 | 让模型只输出 JSON。Ollama、LM Studio 和“自定义”模板默认关闭，其他模板默认打开；服务器不支持这个参数时 Mod 会自动去掉它再试，一般不用管 |
| 额外请求头 / 额外请求体 | 高级用法，例如 `X-Title: SpirePilot`、`{"top_p": 0.9}`。`top_p` 这类采样参数只适合接受它们的 OpenAI 兼容服务，Claude 会直接报 400 错误，用 Claude 时不要加。写错格式时会提示，AI 不会悄悄失败 |
| Anthropic 选项 | 只对 Claude 有效：提示词缓存（省钱、更快，默认打开）、允许服务端回退模型 |

### 5.6 多套配置

可以添加多套配置（例如一个便宜的、一个聪明的），在最上面的 **使用中** 下拉框里切换；下方编辑区显示的始终是“使用中”的那一套。

- 编辑区有没保存的修改时，不能切换、添加或复制（会提示“有未保存的修改：请先保存或还原”）。
- “复制”会复制当前配置并切换到副本；“重命名”是在输入框里填新名字再点“重命名”；
  “删除”要点两次（第一次按钮变成“确认删除？”，3 秒内再点一次），至少保留一个。
- 切换配置后，AI 下一次决策就用新配置（之前接口出错攒下的冷却时间也会清零）；
  如果 AI 已经因为“API 设置有误”暂停，切换后还要到“控制”页点“继续”。

## 6. 第一局：先用“顾问”模式

建议先让 AI 只出主意、不动手，看看它的思路是否靠谱：

1. 打开 **控制** 页，在“模式”里点 **顾问**。
2. 自己开一局游戏。
3. 每当需要做决定（出牌、选奖励、选路线……），“AI 建议”卡片里会显示 AI 的建议和理由。
4. 你可以照着自己操作，或者点 **执行建议** 让它替你做这一步。局面已经变了的建议会显示“建议已过期”，不能再执行。

顾问模式下 AI 不会替你出牌，也不会替你给队友发消息（只会在建议里写出它想说的话）。

## 7. 让 AI 自己玩（控制页）

### 7.1 选择模式

| 模式 | AI 做什么 |
| --- | --- |
| 关闭 | 什么都不做 |
| 全自动 | 战斗、地图、奖励、商店、事件、篝火、开局，全部由 AI 完成 |
| 仅战斗 | 只打战斗回合（包括战斗中的选牌），其余由你操作 |
| 仅非战斗 | 地图、奖励、商店、事件等由 AI 处理，战斗你自己打 |
| 顾问 | 只给建议，可以一键执行（见上一节） |

**让 AI 从头开一局**：先在“角色”页设好角色（[第 9 节](#9-限定角色和打法角色页)），回到游戏主菜单，
在“控制”页先点 **关闭**，稍等一两秒再点 **全自动**，AI 会按你的角色设置自己选角色、设置进阶并开局。

- 之前用“顾问”“仅战斗”等模式打过一局的话，从那个模式直接切到“全自动”，AI 不会在主菜单开局（状态显示“玩家操作”），
  所以要先切到“关闭”。
- 有存档时 AI 会点“继续”接着打存档里的那一局，不会重新选角色和进阶；限定了角色、而存档的角色不在允许列表中时，
  AI 不会继续，需要你自己继续或放弃存档。

### 7.2 随时接管

- **暂停 / 继续**：暂停后 AI 立刻停手；它正在思考的那一步也会被取消，不会在你接手后还替你出牌。
- 你自己打开的界面（暂停菜单、设置、图鉴、查看队友，以及“放弃本局 / 退出 / 断开连接”的确认框）AI 一律不碰。
- 想换模式就直接点另一个模式按钮。

### 7.3 临时指令

“临时指令（只用于下一次决策）”里可以给 AI 一句话，例如：

- `这回合先防御`
- `这次篝火选择休息`
- `这回合先用火焰药水`

点 **发送**（或按回车）后会显示“待使用: …”，AI 下一次决策时会优先照做（前提是游戏里能这么做），这一步执行后自动清除；
也可以点旁边的“清除”取消。**顾问模式**下 AI 不执行操作，指令会一直保留、影响之后的每条建议，用完请手动点“清除”。
想长期生效的要求请写在“角色”页的“打法风格指令”或“路线”页的“路线指令”里。

### 7.4 行为设置

| 开关 | 说明 |
| --- | --- |
| 单步模式（每一步都要你确认） | AI 每想好一步就停下，等你点 **单步执行** 才做。适合观察 AI |
| 跳过无需思考的决策 | 只有一个选项时直接执行，不调用模型（默认开，省钱） |
| 允许整回合计划（更快、更省 token） | 战斗中一次规划整个回合（默认开） |
| LLM 失败时使用规则兜底 | AI 接口暂时不可用时用内置规则先顶着（默认开）。关闭后，接口连续出错 3 次就暂停，不会一直重试花钱；密钥、地址、模型名等设置错误无论开关都会立即暂停 |
| 一局结束后自动开始下一局 / 最多自动开局（0 = 不限） | 挂机连续打多局。只在“全自动”模式下有效，而且只在上一局正常结束（胜利或死亡）的单人局之后才自动开新局；联机局，或者你“保存并退出”、断线回到主菜单后，AI 不会自己开局或继续 |
| 操作间隔 | 每个操作之间等多久，方便你看清 AI 在做什么 |

### 7.5 看懂状态

- 顶部状态：例如“思考中 · 全自动”“等待中 · 全自动”“已暂停 · 全自动”。
  - “等待中”通常是游戏动画没播完、轮到队友，或者打开了只给人看的界面；
  - “玩家操作”表示当前模式把这个界面留给你，例如“仅战斗”模式下的地图，或者 AI 不该在主菜单开局时（见 7.1）。
- “当前局面”：当前界面、幕数和层数、生命、能量、敌人、能做的操作数量。
- “统计”：LLM 调用次数和 token 用量；“最近一次 LLM 错误”会显示接口出了什么问题。
- **清空 AI 记忆**：清掉 AI 的历史记录、备忘和本回合计划，也会清掉它记着的队友请求和答应过的事（例如答应给队友用药水）。
  适合 AI 被之前的局面误导时用；联机时慎用。

### 7.6 AI 自动暂停的情况

AI 遇到下面的情况会自己停下并在状态里说明原因，不会乱点或一直花钱：

- 同一个操作在同一个局面里反复没效果（或来回循环），或者连续失败；
- **API 设置有误**：密钥无效、地址不对、模型名写错、账户余额不足——改好后点 **继续**。
  注意：OpenAI 余额用完时返回的是 429（和限流一样），AI 不会暂停，而是按下一条处理、由内置规则代打；
  “最近一次 LLM 错误”里出现 `quota` 字样就是该充值了。

接口暂时不可用（网络错误、超时、限流）时：连续失败 3 次后先暂停调用模型 60 秒（之后每次翻倍，最长 10 分钟），
期间用内置规则兜底，AI 不会停下（关闭了“LLM 失败时使用规则兜底”时则直接暂停，状态显示“AI 连续多次出错，已暂停”）。
想马上重试：点“暂停”再点“继续”、切换模式，或者在“API”页修改并保存设置。

## 8. 规划路线（路线页）

- **路线偏好**：均衡、激进（多打精英）、稳健（避开精英）、商店优先、问号优先，或“自定义权重”。
  规划器还会考虑你的血量（血少时远离精英、看重篝火）和金币（钱多时看重商店）。
- **房间权重**：选“自定义权重”后，可以分别调整怪物、精英、篝火、商店、宝箱、问号的权重；数值越高越倾向经过，负数表示尽量避开。
- **路线指令**：用一句话告诉 AI 怎么规划，例如 `第一幕至少打两个精英；Boss 前一定要经过篝火`。
- **推荐路线**：进入一局后，这里会列出从当前位置出发的几条路线（不用打开地图）。点 **固定此路线**，AI 就按这条路线走，不再为选节点调用模型。
- **下一步 → 固定这一步**：只想决定下一个节点时，从下拉框里选（左侧 / 正前方 / 右侧）再点“固定这一步”。
  注意它会替换已经固定的整条路线，走完这一步后由 AI 或规划器继续选。
- 固定的路线只对**当前这一局的当前幕**有效，进入下一幕或新的一局自动失效；点“清除”可以随时取消。
  你给了临时指令（或者队友有请求要回应）时，这一步仍交给模型决定，它会看到你固定的路线。
- **由 AI 选择地图节点**：关闭后不调用模型选节点，按固定路线或推荐路线的下一步走。
- **在地图上标记我的选择给队友看**：联机时 AI 选节点前会在地图上标记一下（游戏自带的功能，没装 Mod 的队友也能看到）。

## 9. 限定角色和打法（角色页）

- **允许 AI 选择的角色**：勾选 AI 可以用的角色（全部勾选 = 任意已解锁角色；至少保留一个）。
- **选择方式**：随机、轮流（多局依次轮换）、总是第一个、由 AI 决定（在允许范围内）。
- **进阶等级**：AI 开局时设成这个等级（默认 0；填的数字超过已解锁的最高等级时，按最高等级算）；
  填 `-1` 表示用已解锁的最高等级。进阶由你决定，AI 不会自己改。
- **打法风格指令（长期有效）**：例如 `铁甲战士优先力量流；不要拿诅咒；尽量删除打击`。每次决策 AI 都会看到。
- **提示词内容**：
  - 包含遗物、药水和充能球的描述（更准确，token 更多）；
  - 战斗中包含抽牌堆 / 弃牌堆；
  - 保留的历史决策条数。
- 这些限制是从 AI 的可选操作里直接去掉的，AI 想违反也做不到。例如限定了角色、而存档里的角色不在允许列表中时，
  AI 不会点“继续”，会停在主菜单（状态显示“等待中”），需要你自己继续或放弃这个存档。

## 10. 联机：让 AI 和队友交流（队友页）

### 10.1 谁需要装 Mod

- 游戏本身没有文字聊天。SpirePilot 通过游戏的联机通道发送自己的消息，**只有装了 SpirePilot 的队友能看到文字**。
- **房主也需要装**：客户端之间的消息由房主转发。房主没装时，装了 Mod 的客户端之间也传不了文字。
- 队友页的“队友”卡片会显示每个队友是“已装 SpirePilot”还是“未装 SpirePilot（看不到消息，只能看到表情）”，
  以及他们的血量、药水，和由 AI 还是玩家控制。
- 没装 Mod 的队友也能和 AI 互动：AI 会改用游戏自带的**表情**和**地图标记**，队友也能用表情回答（见 10.4）。

### 10.2 AI 会自己做什么

AI 会根据队友的血量、药水、敌人情况主动沟通（需要打开“AI 主动向队友提出请求”），例如：

- 自己快扛不住时向队友**要药水**、**求保护**；
- 请队友给某个敌人上**易伤 / 虚弱**，或者一起**集火**某个敌人；
- 看到队友血少时**问队友要不要药水**，或者直接提出把某瓶药水给队友用。

AI 发出的消息是它自己写的一句话，每次说法不同。

也会回应队友（需要打开“AI 自动回复队友”）：

- 队友向 AI 要药水，AI 同意后会真的把药水**用在队友身上**（游戏不能直接转交药水，“给药水”就是对队友使用）。
  只能在战斗中给，而且只有游戏允许对队友使用的药水才行；火焰药水这类只能对敌人用的药水给不了；
- 队友请 AI 上减益，AI 会在能做到时照做；
- AI 已经点了结束回合，队友这时求助，AI 会回复；如果需要（比如要给队友用药水），它会**撤销结束回合**回来帮忙；
- 队友对 AI 的提议说“好”，AI 会记住这个承诺，轮到它行动时照做。

为了不刷屏：AI 每分钟发消息有上限，不会重复发同一个请求，两个 AI 队友也不会互相无限聊天。

### 10.3 你自己发消息

**队伍聊天**：

1. “发送给”选“所有人”或某个队友。
2. 输入文字，按回车或点 **发送**。

**快捷请求**（一键发出标准请求，装了 Mod 的队友和他们的 AI 都能看懂）。快捷请求同样发给上面“发送给”里选中的对象，
选中的是没装 Mod 的队友时只会发出对应的表情：

| 按钮 | 发出的内容 |
| --- | --- |
| 要药水 | 能给我一瓶药水吗？我现在需要支援。 |
| 问队友要不要药水 | 有人需要药水吗？我可以给你用。 |
| 求保护 | 我这回合扛不住，能帮我挡一下吗？ |
| 我的药水 → 给药水 | 我有「某某药水」，需要的话我给你用。（先在下拉框里选药水） |
| 目标敌人 → 集火 | 我们一起集火「某敌人」吧。（先选敌人，需要在战斗中） |
| 目标敌人 + 减益 → 要减益 | 选“易伤/虚弱都行”：能给「某敌人」上点减益（易伤/虚弱）吗？选易伤、虚弱或“其他…”（自己填减益名称）：能给「某敌人」上一层「易伤」吗？（敌人取“目标敌人”里选的那个；不在战斗中时写成「敌人」） |

你用快捷请求发出的请求和提议也会记进 AI 的记忆：比如你点“问队友要不要药水”，队友同意后
（没装 Mod 的队友点赞，装了 Mod 的队友回复文字或由他的 AI 回答），AI 会照着去给。
注意：队友页没有“回答”功能；你自己打字发的聊天、手动点的“赞 / 踩”表情，AI 都不知道。
想让 AI 照着做，请用快捷请求，或在“控制”页给临时指令。

### 10.4 和没装 Mod 的队友沟通：表情

没装 Mod 的队友看不到文字。这时 SpirePilot（无论是 AI、你在队友页发的，还是外部工具发的）会改用游戏自带的表情：

| 消息类型 | 队友看到的表情 |
| --- | --- |
| 各种请求（要药水、要减益、集火、求保护） | 感叹号 “!” |
| 问要不要药水、给药水 | 问号 “?” |
| 同意 | 点赞 |
| 拒绝 | 点踩 |
| 聊天、路线建议 | 没有对应的表情，不会发出 |

- 发给“所有人”而队伍里有人装了、有人没装时：文字发给装了的队友，没装的队友看表情。
  表情是游戏自带的，**全队都能看到**（装了 Mod 的队友会同时看到文字和表情），不能只发给某一个人。
- 联机时，只要“发送给”选中的对象里有人没装 Mod（包括选“所有人”而队里有人没装），队友页就会出现
  “发送表情：赞 / 踩 / 感叹号 / 问号”按钮，你也可以手动发。表情只能在对局中发。
- **队友用表情回答 AI**：没装 Mod 的队友点**赞** = 同意、点**踩** = 拒绝。只回答 5 分钟内最近一次用表情发给他（或所有人）的那条请求，
  AI 发的和你在队友页发的都算。如果这一条已经结束，或者之后你（表情按钮）或装了 Mod 的队友又发过“!”“?”，
  这个赞就不算回答任何请求，也不会去回答更早的请求。
- 装了 Mod 的队友要回答 AI 请直接打字：队伍里有没装 Mod 的人时，他们点的表情会被当作是发给那个人的，AI 不会把它算作回答。
- 队友发的“!”或“?”会作为一条简短消息进入 AI 的收件箱，AI 会回应（需要打开“AI 自动回复队友”；对没装 Mod 的队友，
  AI 的回应也只能是表情）。AI 回应过后 45 秒内，同一个队友再发同样的表情只当作背景信息，不会再为它花钱调用模型。
- 收到队友的表情靠的是挂钩游戏内部的函数，作者只在 0.111 上核对过：如果日志里 `team link ready` 那一行写着
  `teammate emotes=False`，说明在你的游戏版本上 AI 收不到队友的表情，点赞回答也不会生效。

### 10.5 队友相关设置

| 开关 / 选项 | 说明 |
| --- | --- |
| AI 自动回复队友 | 关闭后，队友的请求、问题和“!”“?”表情 AI 一概看不到：既不回复，也不会照做（例如不会去上减益、不会给药水）。只有队友对你这边发出的请求（AI 发的或你在队友页发的）给出的同意 / 拒绝仍会传给 AI |
| AI 主动向队友提出请求 | 关闭后 AI 不再主动发起任何请求或提议（要药水、给药水、问要不要药水、要减益、集火、求保护、路线建议），只回答队友；和“AI 自动回复队友”都关闭时，AI 完全不发消息 |
| 允许 AI 对队友使用药水 | 关闭后“对队友用药水”的操作直接从 AI 的选项里去掉，AI 也不会主动提出给药水 |
| 显示对话气泡 | 战斗中把消息显示为角色头顶的气泡 |
| AI 每分钟最多发送消息数 | 防止刷屏（默认 4） |
| AI 消息语言 | 自动 / 中文 / English：AI 发给队友的消息用什么语言 |

### 10.6 消息在哪里看

- **战斗中**：显示为发送者角色头顶的气泡（关闭了气泡，或发送者不在画面上时，改为屏幕提示）。
- **战斗外**：屏幕上弹出提示（同时到了几条，只提示最新一条）。
- 不论战斗内外，只要没在看队友页，收到的队友消息和表情都会计入“AI”按钮和“队友”页签上的未读条数（打开队友页后清零）；
  队友页开着时不弹提示，也不计未读。
- 队伍聊天里能看到完整记录。

### 10.7 几个要知道的细节

- **战斗外的药水只对自己用**：在地图、奖励、商店、篝火、事件等界面，AI 也会用游戏允许的药水（例如果汁、鲜血药水），
  但只对自己；联机时选项写成“使用药水 X → 自己”。想给队友用药水，要等到战斗里。
- 奖励界面药水栏满了，AI 可以先喝掉一瓶能在战斗外使用的药水（例如鲜血药水、果汁）给新药水腾位置，而不只是丢弃；
  只能在战斗中用的药水只能丢弃。
- **消息会过期**：队友消息 3 分钟后过期，请求 5 分钟后（或者所在的战斗 / 回合结束后）过期。
- **“仅非战斗”模式下战斗由你来打**：这场战斗里队友发来的战斗请求（要格挡、减益、集火、要药水以及“!”“?”），
  战斗结束后作废，AI 不会到奖励界面才去回应。
- 敌人按游戏内部的战斗编号传递，两边游戏语言不同也能对上同一个敌人。

### 10.8 示例：一场联机战斗

1. 你和朋友 A（装了 Mod）、朋友 B（没装 Mod）三人联机，房主是你或 A（如果 B 当房主，你和 A 之间连文字都传不过去）。
   你的 AI 在“全自动”模式，“允许 AI 对队友使用药水”保持打开。
2. 第 3 回合 B 血量很低。你的 AI 向所有人发出一条“问队友要不要药水”：A 收到的是 AI 自己写的一句话
   （例如“B 血很低，有人需要药水吗？我有鲜血药水可以给”，每次说法不同），全队（包括 A）都会看到你的角色上方出现一个“?”表情。
3. B 点赞。你的 AI 把这当作对它提议的同意，轮到它行动时把鲜血药水用在 B 身上。
4. A 在自己的面板点“要减益”，选了敌人和“易伤”（全队会看到 A 发出一个“!”）。你的 AI 收到请求，用一句自己写的话答应
   （例如“好，这回合我给它上易伤”；B 会看到一个赞），这回合优先打出能上易伤的牌。

## 11. 日志页和其他设置

- **运行记录**：AI 的每次决策、操作、队友消息、信息和错误，可以按类型筛选或搜索。
- **日志文件**：显示日志的完整路径，可以“复制路径”“打开文件夹”。
- **诊断**：
  - **生成诊断报告**：把版本、补丁、当前界面、游戏状态和最近的日志写进一个文件（不包含 API Key），反馈问题时附上它；
  - **保存决策记录（traces）**：每一步提供了哪些选项、选了什么、结果如何，都存到 `traces/*.jsonl`。
- **其他设置**：界面语言、显示 / 隐藏快捷键、启动游戏时显示面板、界面缩放、把完整提示词写入日志（调试用，日志会变大）。
- **本地 HTTP API（供外部 AI 工具使用）**：单独一张卡片，在这里启用接口、改端口和访问令牌（见[第 15 节](#15-进阶让外部-ai-工具来玩)）。

## 12. 版本提示：红色和黄色

Mod 读到游戏版本后会和包对应的版本比较，结果显示在“控制”页和屏幕提示里：

| 提示 | 情况 | 怎么办 |
| --- | --- | --- |
| 没有提示 | 包和游戏一致 | 正常使用 |
| **黄色**：未经测试 | 游戏比最新的包还新（例如 game0.111 包 + 游戏 0.112） | AI 照常运行，部分功能可能失效；留意 SpirePilot 更新 |
| **红色**：AI 已关闭 | 包和游戏不兼容（例如 game0.107 包 + 游戏 0.111） | 按提示换成对应的包；还没有对应的包时，等 SpirePilot 更新 |

红色提示下，“控制”页会出现 **仍然运行（风险自负）** 开关：打开后模式先切到“关闭”，再自己选一个模式，AI 就会强行运行
（可能读错界面或操作失败）。这个开关只对当前这个游戏版本 + 这个包有效，换了游戏版本或包会重新拦截。
被拦截期间你保存的模式不会被改掉，换对包以后照旧运行。

## 13. 省钱小技巧

- 打开“跳过无需思考的决策”和“允许整回合计划”（默认都是开的）。
- 战斗回合用较低的思考强度（“战斗回合思考强度”）。
- 用 Claude 时保持“提示词缓存”打开（默认就是开的）：连续决策时，系统提示词部分只按原价的大约十分之一计费
  （第一次写入缓存稍贵一些；超过 5 分钟没调用缓存会过期，要重新写入）；每次的游戏状态部分仍按原价计费。
- 在“角色”页关掉“包含遗物、药水和充能球的描述”能省一些 token，但 AI 就看不到这些效果说明了。
- 用“固定此路线”让 AI 不再为选路线调用模型。
- 想零成本：用本地模型（Ollama / LM Studio）。
- 想比较不同模型的水平：可以用离线评测工具给模型打分，不用开游戏（见 [BENCHMARK.md](BENCHMARK.md)）。

## 14. 常见问题

**面板打不开？**
确认 Mod 已加载：日志里应有 `SpirePilot ready`（日志位置见[第 16 节](#16-反馈问题)；数据文件夹里根本没有日志，说明 Mod 没被加载）。
如果日志里同时有 `overlay failed to initialize`，说明面板没能加载，请按第 16 节反馈。
面板默认在左上方显示；被你收起来了就按 F8 或点屏幕右侧的“AI”按钮；快捷键可以在“日志”页改。

**AI 一直显示“等待中”或“玩家操作”？**
- 游戏动画或行动队列还没结束、轮到队友、或者你打开了暂停菜单 / 图鉴等只给人看的界面时，AI 会等待，关掉这些界面即可。
- 当前模式不负责这个界面时（例如“仅战斗”模式在地图上、非“全自动”模式在主菜单），顶部会显示“玩家操作”、
  下面写“等待中: Map”之类，这一步要你自己做。
- 在主菜单不动时：之前用别的模式打过一局的话，先点“关闭”、稍等一两秒再点“全自动”；上一局结束后想让 AI 自动开下一局，
  要打开“一局结束后自动开始下一局”；存档的角色不在允许列表中时，AI 不会继续存档，需要你自己处理。

**AI 暂停并提示 API 设置有误？**
检查密钥、接口地址（OpenAI 兼容接口一般要包含 `/v1`）、模型名和账户余额，改好后在“API”页点“保存”，再到“控制”页点“继续”。

**测试连接失败？**
看失败信息：
- `401` / `403` 一般是密钥不对；
- `402`，或提示 Insufficient Balance / 余额不足，是账户没钱；
- `404`，或 `400` 且提示 Model Not Exist / 模型不存在 / not a valid model，是地址或模型名不对；
- 超时或连不上多半是网络问题，海外服务请填代理。

**队友收不到我的消息？**
对方（以及房主）需要安装同版本的 SpirePilot。队友页会显示谁装了 Mod；没装的队友只能看到表情和地图标记。

**AI 在奖励界面喝掉了药水？**
战斗外 AI 也会用药水（只对自己），比如血量低又没有篝火时喝治疗药水，或者药水栏满了为更好的药水腾位置。
不希望它这样做，可以在“角色”页的“打法风格指令”里写上，例如“战斗外不要用药水”。

**会影响成就和存档吗？**
游戏加载 Mod 时会自动使用单独的 Mod 存档。SpirePilot 不修改任何游戏数据，只通过正常操作游玩。

## 15. 进阶：让外部 AI 工具来玩

除了内置 AI，你也可以让 Claude Desktop、Claude Code、Cursor 等外部 AI 工具，或者你自己写的脚本来玩：

1. 在“日志”页的“本地 HTTP API（供外部 AI 工具使用）”卡片里打开“启用”（默认端口 17654，只监听本机，可设置访问令牌）。
   卡片里显示“运行中: http://localhost:17654/”才算开好；显示“未运行”多半是端口被占用，换一个端口。
2. 在“控制”页把模式设为“关闭”或“顾问”（内置 AI 在操作时外部工具不能操作）。
3. 连接外部工具，二选一：
   - **MCP 服务器**：它不在 Mod 压缩包里，需要另外下载 SpirePilot 的源码仓库，并安装 Python 3.10+ 和 uv。
     下面的 `/path/to/SpirePilot` 是源码仓库的位置（不是游戏的 `mods` 文件夹）：

     ```bash
     claude mcp add spirepilot -- uv run --directory /path/to/SpirePilot/tools/mcp spirepilot-mcp
     ```

     设置了访问令牌时改成 `claude mcp add spirepilot -e SPIREPILOT_TOKEN=你的令牌 -- uv run …`。
   - **直接调用接口**：`curl "http://localhost:17654/state?format=text"`
     （设置了令牌时加上 `-H "Authorization: Bearer 你的令牌"`）。

   Windows 上请用 `localhost`，不要用 `127.0.0.1`。

外部 AI 看到的状态和可选操作与内置 AI 相同，你的角色限制、“不允许把药水给队友”等规则对它同样生效。
接口细节见 [README 的“本地 HTTP 接口”](../README.md#本地-http-接口给外部-ai--脚本用默认关闭)，MCP 用法见 [tools/mcp/README.md](../tools/mcp/README.md)。

## 16. 反馈问题

遇到 AI 卡住、操作失败或界面读错时：

1. 在“日志”页点 **生成诊断报告**。
2. 找到数据文件夹（“日志”页“打开文件夹”，或下面的位置），把这些文件发给作者：
   - `diagnostics-*.md`：诊断报告；
   - `spirepilot.log`：日志（上一次游戏的日志是 `spirepilot.log.prev`）；
   - 如有需要，`traces/` 里当天的决策记录。
3. 写清楚：在哪个界面、做了什么、AI 做了什么、你期望它做什么。

数据文件夹在游戏用户数据目录下的 `mod_configs/SpirePilot/`（不在 `mods` 文件夹里），Windows 通常是
`%APPDATA%\SlayTheSpire2\mod_configs\SpirePilot\`。以游戏实际的用户目录为准：“日志”页的“日志文件”卡片会显示完整路径，
`spirepilot.log` 开头 `SpirePilot <版本> starting; data dir …` 那一行也写着数据文件夹的位置。
**`settings.json` 里有你的 API Key，不要分享它**（或者先用 `env:` 写法把密钥移到环境变量里）。

想自己逐项验证各个功能，可以照着 [TESTING.md](TESTING.md) 的实机测试清单走一遍。

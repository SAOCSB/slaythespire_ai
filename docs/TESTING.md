# 实机测试清单 / In-game test plan

SpirePilot 是在没有游戏的环境里、按游戏真实程序集编译出来的，**还没有在真实游戏里跑过**。
下面这份清单按风险从低到高排列，照着走一遍就能快速定位问题。每一步出问题时：
打开面板 → “日志”页 → 点 **生成诊断报告**（或访问 `http://127.0.0.1:17654/diagnostics`），
把生成的 `diagnostics-*.md` 和 `spirepilot.log` 一起反馈。

> 建议先用 **顾问模式** 或 **单步模式** 测试，确认 AI 想做的事是对的，再开全自动。

## 0. 加载
| # | 操作 | 期望 |
| --- | --- | --- |
| 0.1 | 按 README 安装，启动游戏 | 游戏正常进入主菜单；Mod 列表里有 SpirePilot |
| 0.2 | 打开 `mod_configs/SpirePilot/spirepilot.log` | 有 `SpirePilot ready`，没有 `failed to initialize` |
| 0.3 | 按 F8 / 点右上角 AI 按钮 | 面板出现，中文正常显示（没有方块字），可拖动 |
| 0.4 | 在面板输入框里打字（含字母 E、数字键、空格） | 游戏本身没有响应这些按键（不会结束回合、不会打牌） |

## 1. AI 接口
| # | 操作 | 期望 |
| --- | --- | --- |
| 1.1 | API 页选预设、填 Key、点“测试连接” | 显示成功和耗时；失败时有明确原因（401/地址/模型名） |
| 1.2 | 故意填错 Key，开顾问模式进入战斗 | AI 暂停并提示“AI 设置有误”，不乱操作 |
| 1.3 | AI 正在“思考中”时点暂停 / 切到关闭 | 这一步被取消，不会在你暂停后还打出牌或发消息 |
| 1.4 | 关闭“AI 失败时用规则兜底”，把地址改成不存在的服务器 | 连续失败 3 次后暂停并提示，不会一直重试 |

## 2. 单人战斗（先顾问模式，再“只打战斗”）
| # | 场景 | 期望 |
| --- | --- | --- |
| 2.1 | 第一场战斗，顾问模式 | 状态显示“建议: 打出 …”，理由合理；日志里能看到完整的菜单 |
| 2.2 | 切到“只打战斗” | AI 打出卡牌（含需要选目标的攻击）、结束回合；动画期间显示“等待中” |
| 2.3 | 手牌选择（例如“丢弃 1 张牌”的牌） | AI 选牌并确认，不会卡住 |
| 2.4 | 有药水时的精英/Boss 战 | AI 会在关键回合用药水；用在正确目标上 |
| 2.5 | 发现/三选一（战斗中生成牌） | AI 选一张，界面关闭 |
| 2.6 | 战斗结束 | 奖励界面交给你（只打战斗模式下） |
| 2.7 | 手里有两张同名但不同（一张附魔/本回合 0 费）的牌 | AI 选的是哪一张就打出哪一张 |
| 2.8 | 有毒、厄运（Doom）、缠绕、沙坑等状态时看“Threat”行 | 会致死时明确写出（厄运在回合结束时判定，与格挡无关） |

## 3. 战斗外（“只管战斗外”或全自动）
| # | 场景 | 期望 |
| --- | --- | --- |
| 3.1 | 奖励界面 | 领取金币/药水/遗物；卡牌奖励会打开并选择或跳过；药水栏满时只给出“丢弃药水”的选项 |
| 3.2 | 地图 | 选择可到达的节点；路线页列出路线；“固定此路线”后严格按路线走 |
| 3.3 | 商店 | 打开商品、只买得起的东西、可以删牌（会打开选牌界面）、离开 |
| 3.4 | 问号事件（含多页、先古之民） | 选择选项，事件结束后继续 |
| 3.5 | 篝火 | 低血休息、高血锻造（会打开升级选牌），然后继续 |
| 3.6 | 宝箱 | 打开、拿遗物、继续 |
| 3.7 | 教程弹窗 / 确认弹窗 | 自动关闭教程；你自己打开的“放弃本局 / 退出 / 断开”确认框 AI 完全不碰 |
| 3.8 | 先古之民（Neow 等）多句对话 | AI 一句句点过对话，不会因为“重复操作”而暂停 |
| 3.9 | 在路线页提前固定路线（不在地图界面时） | 可以看到路线并固定；下一局开始时旧路线自动失效 |

## 4. 开局与角色限定（全自动）
| # | 场景 | 期望 |
| --- | --- | --- |
| 4.1 | 角色页只勾选一个角色，主菜单切到全自动 | AI 进入角色选择、选中该角色、设置进阶、出发 |
| 4.2 | 勾选的角色都没解锁 | AI 暂停并提示 |
| 4.3 | 死亡/胜利 | AI 点继续回到菜单；开了“自动开下一局”才会再开 |
| 4.4 | 轮换模式下连续两局 | 角色按顺序轮换 |
| 4.5 | 进入角色选择时游戏已默认选中一个角色 | 仍按你设置的策略（随机/轮换/第一个）改选角色，并设置进阶 |
| 4.6 | 存档里是未允许的角色，主菜单切全自动 | AI 不会点“继续”，提示你自行处理存档 |
| 4.7 | 局中“保存并退出”回到主菜单 | AI 不会自动继续或开新局 |

## 5. 多人（需要两台装了 SpirePilot 的电脑；房主必须安装）
| # | 场景 | 期望 |
| --- | --- | --- |
| 5.1 | 建房/加入后查看日志 | 有识别到对方 Mod 的日志（team link）；队友页显示对方“已安装 SpirePilot” |
| 5.2 | 队友页发送一条聊天 | 对方面板收到；战斗中对方角色头顶出现气泡 |
| 5.3 | 快捷按钮：要药水 / 问要不要药水 / 要减益（选敌人）/ 集火 / 求保护 | 对方收到对应文字；对方 AI 会接受/拒绝并执行（例如把能对玩家使用的药水用在你身上） |
| 5.4 | 一方 AI、一方人类 | AI 低血时会主动请求；不会刷屏（每分钟有上限），不会和另一个 AI 无限对话 |
| 5.5 | 地图投票 | AI 投票前会在地图上 ping；投完票后等待队友，不会反复点击 |
| 5.6 | 结束回合 | AI 结束回合后显示“等待队友”，不会再操作 |
| 5.7 | 和**没装** SpirePilot 的队友联机 | 正常联机不报错；状态里标明“无 SpirePilot”；AI 想请求时改为发游戏自带的表情（点赞/问号等）；地图 ping 依然可见 |
| 5.8 | AI 已结束回合，队友这时向它要药水 | AI 会回复；必要时“撤销结束回合”把药水用在队友身上 |
| 5.9 | 请求对某个敌人上减益（两边游戏语言不同） | 对方 AI 收到的是它自己画面里的同一个敌人（按战斗 id 对应） |
| 5.10 | 三人局（两个客户端都装 Mod） | 客户端之间也能互相识别、直接发消息 |
| 5.11 | 你在顾问模式 | AI 只在面板上建议要说的话，从不替你发消息 |

## 6. 外部接入
| # | 操作 | 期望 |
| --- | --- | --- |
| 6.1 | 日志页开启 HTTP API，`curl http://127.0.0.1:17654/state` | 返回 JSON 状态和合法操作 |
| 6.2 | 模式设为关闭，`curl -X POST .../act -d '{"id":"a0"}'` | 执行该操作 |
| 6.3 | 按 tools/mcp/README.md 接入 Claude Desktop / Claude Code | MCP 工具可读取状态、执行操作 |
| 6.4 | 浏览器里打开任意网页 | 网页无法通过本地接口操控游戏（带 Origin 的请求一律拒绝） |
| 6.5 | `dotnet run --project tools/SpirePilot.Bench -- --settings 你的配置.json` | 离线跑 28 个决策题，看模型得分（见 docs/BENCHMARK.md） |
